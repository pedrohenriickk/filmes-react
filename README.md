# 🎬 Lista de Filmes Favoritos

Uma aplicação em React desenvolvida para organizar e acompanhar o status de exibição de filmes, permitindo alternar facilmente entre os estados de **Assistido** e **Não assistido**.

---

## 🚀 Funcionalidades

- **Listagem de Filmes:** Exibição clara dos títulos e seus respectivos anos de lançamento.
- **Alternância de Status:** Botão interativo para alterar a situação do filme em tempo real.
- **Painel de Resumo:** Indicadores dinâmicos que contabilizam:
  - Total de filmes cadastrados.
  - Total de filmes já assistidos.
  - Total de filmes pendentes (não assistidos).
- **Design Responsivo:** Adaptado para telas de computadores e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **React.js** — Biblioteca para construção da interface de usuário.
- **Vite** — Build tool rápida para desenvolvimento Web.
- **CSS3** — Estilização com suporte a Flexbox, CSS Grid e Media Queries.
- **JavaScript (ES6+)** — Manipulação de estado e lógica da aplicação
